A cutting-edge, dynamic, and futuristic developer portfolio designed to captivate visitors with **Spatial Glassmorphism**, **WebGL 3D Interactive Core (Three.js)**, **tactile Cybernetic Sound FX**, and a **Real-Time Security Intelligence Terminal**.

## ⚡ Live Features

1. **Spatial VisionOS Architecture**
   - Multi-layered refractive frosted glass (`backdrop-filter: blur(24px)`)
   - Interactive 3D Perspective Tilt with real-time specular lighting sheen (`rotateX / rotateY / translateZ`)
   - Luminous chromatic ambient backlights (Cyan, Violet, Emerald)
   - Custom Precision Cyber Crosshair & Trailing Aura

2. **Interactive 3D Quantum Defense Core (Three.js)**
   - Real-time rotating wireframe icosahedron and gyroscopic cryptographic rings
   - Interactive drag-to-rotate in 3D space with touch & mouse support
   - Switchable Defense Modes: **Quantum Shield (Kyber-1024 PQ)**, **Zero-Trust Mesh (mTLS X25519)**, **Neural Sentinel (AES-256-GCM)**

3. **Interactive Security Command Terminal**
   - Authentic spatial glass CLI (`vance@apex-09:~$`)
   - Interactive commands: `whoami`, `skills`, `projects`, `scan`, `certs`, `contact`, `easteregg`, `clear`
   - Real-time animated perimeter penetration & port audit simulation
   - Quick-action command pills for instant one-click execution
   - Terminal history navigation (Up/Down arrow keys) and one-click key copying

4. **Synthetic Web Audio API Sound Synthesizer**
   - Zero external audio files required (100% synthesized in-browser, 0ms latency)
   - Subtle futuristic hover blips, click chirps, mode engage sound, and audit sweep chords
   - Respectful default: muted by default with an instant one-click toggle & animated equalizer in the navigation dock

5. **Operational Projects with Holographic Protocol Inspector**
   - Interactive 3D project cards with CVE mitigations and benchmark metrics
   - "INSPECT PROTOCOL" holographic modal detailing threat models, attack surface mitigations, and architectural layers
   - Filterable by Category (`Security`, `Systems`, `Cloud`)

6. **Encrypted Direct Transmission Ingress**
   - PGP Public Key card with verified fingerprint and one-click copy
   - End-to-end encrypted dispatch simulation form with particle celebration burst

## 🛠️ How to Customize with Your Own Information

All content is centralized in **a single configuration file**:
👉 [`src/config/portfolio.config.ts`](file:///c:/Users/Bakachiki/Desktop/PROJECTS/Portfoilio/src/config/portfolio.config.ts)

Simply edit this file to update:
- Your name, clearance, and bio: `portfolioConfig.personal`
- Your social links, PGP key, and email: `portfolioConfig.socials`
- Your cybersecurity & software engineering skills: `portfolioConfig.skillsCategories`
- Your projects, metrics, and threat models: `portfolioConfig.projects`
- Your verified certifications (OSCP, CISSP, AWS, etc.): `portfolioConfig.certifications`

## 🚀 Development & Deployment

### Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the live site.

### Production Build
```bash
npm run build
npm run start
```

### Deploy to Vercel
Deploying takes less than 60 seconds:
1. Push this repository to GitHub.
2. Import the repository in [Vercel](https://vercel.com).
3. Framework preset will automatically detect **Next.js**. Click **Deploy**!
